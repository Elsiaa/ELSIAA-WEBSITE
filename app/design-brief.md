# ELSIAA — design brief

**Design read** — Business owners skeptical of AI hype; the site must earn a laugh, then earn trust. Emotional register: wit first, precision after.

**Concept spine** — "Throw the old web away." The visitor scrubs, in one continuous pinned scroll, the death of a bad website (told in deliberately terrible MS Paint) and lands in the clean world ELSIAA actually builds. The contrast IS the pitch: we can draw badly on purpose because we build beautifully for a living.

**Delivery tier** — spectacle (A4 seam-locked scroll scrub, single pinned journey, scroll drives a rendered film).

**Locked palette** — #FFFFFF page, #111111 ink, #E53E3E strike-red (the only loud color, used only for destruction), #1e6b3c / #2e9e58 hunter green (brand accents, CTA), #F5F5F3 warm panel gray. Defense: Apple-white credibility frame around an intentionally crude cartoon; green is the ELSIAA signature and appears only where ELSIAA speaks.

**Locked type** — system stack (-apple-system/Inter) for hero + UI; Cormorant Garamond italic solely for "Omnia possibilia"; IBM Plex Mono for city register. Justification: brand kit already ratified across cards/site v1.

**Tier-1 technique** — A4 seam-locked scroll scrub. Journey: hero text → red strikethrough (SVG stroke draw) → hero shrinks into monitor of MS Paint office still → 10s destruction film scrubbed frame-exact (all-keyframe H.264) → white reset → wireframe node-lion globe → services. Camera: fixed viewport, media swaps at seams (hero DOM ↔ still ↔ video ↔ DOM). Mobile: same journey, shorter scrub distance, tap-to-skip affordance. Reduced motion: static chapter stack, video paused poster.

**Section plan** — 1 pinned journey (hero/strike/morph/film/reset) + services grid (cards) + global CTA band + footer register. Families: typographic hero, film canvas, 3-col card grid, split CTA, mono footer. Eyebrow budget: 2.

**Asset plan** — office_scene.jpeg (approved Gemini still, uploaded to Higgsfield as start frame), destruction.mp4 + destruction_ballcam.mp4 (Kling 3.0 Turbo jobs 76a61da8 / aa39c9ca from that start frame, re-encoded g=1), inline SVG monogram favicon, OG cover (constellation lion, nano banana).

**CTA inventory** — "Explore" (hero: ghost pill, dissolves on strike), "Get in touch" (CTA band: solid hunter green, magnetic hover-lift), "See services" (post-film: underline-draw link). No shared button class.
